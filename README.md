# Project2030_MySafeFirst

## Overview
Project2030_MySafeFirst is a community-driven initiative aimed at enhancing safety and security for individuals and families. This application leverages modern technology to provide users with tools and features that promote safety awareness and preparedness.

## Features
- **Emergency Alerts**: Instantly notify your contacts in case of emergencies.
- **Local Safety Resources**: Access a database of nearby emergency services, shelters, and safety tips.
- **Real-time Tracking**: Share your location with chosen contacts during critical situations.
- **Safety Planning**: Create customized safety plans for different scenarios.

## Tech Stack
- **Frontend**: React.js, HTML, CSS
- **Backend**: Node.js, Express.js
- **Database**: MongoDB
- **Deployment**: Heroku/AWS

## Setup Instructions
1. Clone this repository:
   ```bash
   git clone https://github.com/Shermaine813/Project2030_MySafeFirst.git
   cd Project2030_MySafeFirst
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Set up your environment variables following the `.env.example` file.
4. Start the development server:
   ```bash
   npm start
   ```

## Usage Examples
- To send an emergency alert, click on the "Emergency Alert" button in the app.
- To view local safety resources, navigate to the "Resources" section on the dashboard.
- You can create a safety plan by following the prompts under the "Plan" section.
